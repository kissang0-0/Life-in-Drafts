# FEATURE: MEMORY JAR

## Purpose

Memory Jar is a collection of the user's most meaningful moments.

Think of it as a digital keepsake box.

A place where favorite memories are stored safely and rediscovered later.

Unlike Dear Me, which stores everything, Memory Jar only contains moments worth remembering.

The goal is nostalgia, gratitude, reflection, and growth.

---

# CORE CONCEPT

The user can save memories from anywhere in the app.

Sources:

* Dear Me entries
* Unsocial ME-dia posts
* My Unsent Messages
* To Do/n't achievements
* Study Sanctuary milestones
* Cycle & Error reflections

Saved moments become "Memory Slips."

---

# MEMORY JAR HOME

Display a beautiful glass jar.

The jar should gradually fill with memory slips.

Not a list.

Not a folder.

An actual visual memory jar.

As memories increase:

* More paper slips appear
* Jar becomes fuller
* Visual celebration of lived experiences

---

# MEMORY SLIPS

Each memory contains:

* Title
* Date
* Source
* Preview
* Mood
* Photos (optional)

Display as folded paper notes.

---

# SAVE TO MEMORY JAR

Every major feature should have:

⭐ Save to Memory Jar

button.

One tap saves memory.

---

# RANDOM MEMORY FEATURE

Core feature.

"Pull a Memory"

Random memory appears.
