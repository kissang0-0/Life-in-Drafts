FEATURE: LIGHTS OUT
Sleep Tracker & Night Recovery System
Purpose

Create a sleep tracking feature called Lights Out.

This feature helps the user understand their sleep patterns, improve rest quality, and build a calming night routine.

It should feel like closing the day gently, not monitoring performance.

Lights Out connects with:

Afterthoughts (night writing)
Forkcast (nutrition & recovery)
Sip Happens (hydration balance)
Glow Cycle (wellness phases)
Cloud Corner (sleep insights)
Nimbus (night companion)
Visual Concept

Sleep is represented as a night sky system.

Deep navy-blue background
Slow-moving stars
Soft glowing moon
Clouds drifting slowly across screen

Each sleep session adds stars to the sky.

Better sleep = brighter sky.

Poor sleep = cloudy night sky.

Bedtime Mode

When user activates bedtime mode:

Screen transitions into:

🌙 Sleep interface

Features:

Dimmed UI
Slow animations
Nimbus becomes quiet mode
“Goodnight” message appears

Example:

“It’s time to rest. I’ll be here when you wake up.”

Wake-Up Check-In

When user opens app in the morning:

Nimbus asks:

“How did you sleep?”
“Do you feel rested?”

Options:

Fully rested
Somewhat rested
Still tired

This updates sleep insights.

Sleep Streak System

Track consistency:

Example:

Sleep Streak:
5 Days

Average Sleep:
6.8 Hours

Reward consistency, not perfection.

Sleep Quality Analysis

Track patterns:

Bedtime consistency
Sleep duration average
Rest quality trends

Example insights:

“You sleep better when you go to bed before 11 PM.”
“Long study days slightly reduce sleep quality.”
“Weekends show irregular sleep patterns.”
Mood Integration

Sleep affects Mood Garden:

Good sleep → brighter flowers, stable moods
Poor sleep → wilted or cloudy garden visuals

This creates emotional awareness of rest.

Closing a chapter of the day
