HOME DASHBOARD & DEAR ME CORE SYSTEMS

HOME DASHBOARD

The home screen is the emotional center of Life in Drafts.

It should feel warm, personal, and alive.

DASHBOARD CONTENT

Display:

Current date
Greeting message
Today’s mood summary
Writing streak
Task overview
Study progress
Recent diary entry
Memory reminder

Include shortcuts:

Write Diary Entry
Add Task

Write Unsent Message
Start Study Timer
DAILY CARD

Include a rotating daily card:

Quote of the day
Nimbus message
Mood suggestion

“Small steps still move you forward.”
