FEATURE: NIMBUS' NEST
Overview

Create a new feature called Nimbus' Nest inside Life in Drafts.

Nimbus' Nest is a private AI companion and conversational space where the user can freely talk with Nimbus.

Nimbus is not an assistant.

Nimbus is not a productivity coach.

Nimbus is not a therapist.

Nimbus is a gentle companion that helps the user reflect, process thoughts, celebrate progress, understand emotions, and navigate life.

The experience should feel like talking to a trusted friend beneath a calm night sky.

This feature must work with:

Expo SDK 54
Firebase
Groq API
Single-user architecture

The user is the only user of the application.

AI Integration

Connect Nimbus to Groq API.

Use Firebase Cloud Functions.

Never expose API keys inside Expo code.

Store API key as:

GROQ_API_KEY

inside Firebase environment variables.

All requests should flow through Firebase.

User Experience Goal

Nimbus' Nest should feel like the emotional heart of Life in Drafts.

The user should feel like they are talking to someone who remembers their story, understands their growth, celebrates their wins, sits with them during difficult days, and walks beside them through every chapter of The Archive of Becoming.

Create a polished, production-ready implementation integrated with the existing Firebase architecture and all existing Life in Drafts features.
