# FEATURE: UNSOCIAL ME-DIA

## Purpose

Unsocial ME-dia is a private social media platform that exists only for the owner.

It should feel like Instagram, Twitter/X, Threads, Tumblr, and a personal scrapbook combined.

No one else can see the content.

There are:

* No followers
* No friends
* No public profiles
* No sharing
* No messaging

The owner is the only user.

The purpose is to document thoughts, daily life, emotions, rants, wins, memories, and random moments in a familiar social media format.

---

# Home Feed

Create a vertically scrolling feed.

Display posts in reverse chronological order.

Newest posts first.

Each post should display:

* Date
* Time
* Content
* Images
* Mood
* Tags
* Favorite status

---

# Create Post

Users can create a new post.

Fields:

* Text content
* Mood
* Images
* Tags
* Location (optional)
* Favorite toggle

---

# Mood Options

Allow:

😀 Happy

😌 Calm

😔 Sad

😡 Angry

😰 Anxious

🤩 Excited

😴 Tired

😶 Neutral

Store mood with post.

# Character Counter

Display live character count.

Suggested limits:

* Soft warning at 500 characters
* Hard limit at 5000 characters

# Image Posts

Allow:

* Multiple image uploads

* Gallery

Display:

* Single image view
* Swipeable image carousel

# Self Interactions

Since this is a platform for one person:

Allow:

* Like own posts
* Save own posts
* Comment on own posts
* Add reflections later

Example:

Original Post:
"I was nervous today."

Reflection Added Months Later:
"Turns out everything worked out."

---

# Post Reflections

Allow users to revisit old posts.

Add a reflection section.

Fields:

* Reflection text
* Reflection date

Useful for personal growth.

# Empty State

---

# User Experience Goal

The user should feel like they have their own private social network.

A place to rant.

A place to celebrate.

A place to remember.

A place to look back and see growth.

Unsocial ME-dia should feel like:

"The internet, but only for me."
