# FEATURE: SECRET VAULT

## Purpose

Secret Vault is the most private space inside Life in Drafts.

A hidden sanctuary for thoughts, memories, photos, messages, and reflections that the user wants extra protection for.

This is not simply storage.

It should feel like entering a secret room that only the owner knows exists.

---

# ACCESS SYSTEM

The Vault should require additional authentication.

Options:

* Secondary PIN
* Face ID
* Fingerprint
* Device Authentication

User chooses preferred method.

---

# HIDDEN ENTRY MODE

Provide optional stealth mode.

When enabled:

Secret Vault should not appear in:

* Navigation
* Home Dashboard
* Search
* Settings shortcuts

Access only through:

Custom gesture

Examples:

* Tap Nimbus 5 times
* Long press app logo
* Secret PIN sequence

User can configure preferred access method.

---

# VAULT HOME

Upon entering:

Display a calm hidden sanctuary.

Theme:

* Moonlit library
* Hidden archive room
* Secret observatory
* Cloud attic

Allow user to choose theme.
